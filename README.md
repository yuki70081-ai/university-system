# University Management System

This is a TypeScript project for managing a university.

## Features
- Manage students and teachers
- Create courses and academic groups
- Add student grades and calculate average scores
- Manage faculties
- Store and retrieve student data

## Technologies
- TypeScript
- Object-Oriented Programming (OOP)

## OOP Concepts
- Inheritance
- Encapsulation
- Polymorphism
- Abstraction
- Aggregation and Composition

## How to Run

```bash
npx tsx main.ts
```
